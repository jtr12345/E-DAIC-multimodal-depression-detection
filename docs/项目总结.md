# E-DAIC 多模态抑郁识别项目完整总结

## 1. 项目目标

本项目使用 Extended DAIC-WOZ（E-DAIC）访谈数据，研究文本、音频和视频信息能否帮助识别 PHQ-Binary 抑郁风险，并逐步比较：

- 不同模态的预测能力
- 不同特征表示
- Linear SVM、Logistic Regression、随机森林和 XGBoost
- Early Fusion 与 Late Fusion
- 固定参数、内层调参、阈值选择和融合权重选择

本项目输出的是研究数据上的二分类预测结果，不是临床诊断系统。

## 2. 数据、标签与统一评估规则

- 数据集：Extended DAIC-WOZ
- 参与者：275 人
- 目标标签：PHQ_Binary
- 正类人数：66；负类人数：209
- 模态：文本转录、音频 WAV、OpenFace 视频特征
- 663 号参与者的缺失 Transcript 和 OpenFace 文件已经补齐
- result_1 使用官方 train/dev/test 划分
- result_2 至 result_6 和 result_repo_style 使用相同的五折参与者级交叉验证
- 五折实验每折约 220 人训练、55 人验证
- 主要指标：Macro-F1、AUROC、Balanced Accuracy

Macro-F1 反映固定阈值后的分类表现，AUROC 反映预测分数对正负样本的排序能力。类别不平衡时，不能只看 Accuracy。

## 3. 特征版本

### 3.1 早期基线特征

- 文本：TF-IDF，再用 TruncatedSVD 降维
- 音频：OpenSMILE eGeMAPS 统计特征
- 视频：OpenFace 数值特征的均值和标准差

### 3.2 预训练 embedding

- 文本：RoBERTa-base，768 维
- 音频：Wav2Vec2-base，768 维
- 视频：OpenFace 统计特征

预训练 embedding 版本使用 GPU 在本地重新提取。它与 GitHub 仓库的方法方向一致，但不是作者 notebook 的逐行复现。

## 4. result_1：官方 train/dev/test 基线

### 方法

- 数据划分：官方 train/dev/test
- 模型：文本、音频、视频单模态模型，以及 Early Fusion、Late Fusion
- 特征：TF-IDF/SVD、OpenSMILE、OpenFace
- 主要观察指标：官方 test split

### Test 结果

| 模型 | Macro-F1 | AUROC |
|---|---:|---:|
| Text | 0.650 | 0.698 |
| Audio | 0.622 | 0.742 |
| Video | 0.605 | 0.638 |
| Early Fusion | 0.666 | 0.744 |
| Late Fusion | **0.657** | **0.769** |

### 结论

- 官方 test split 上，Late Fusion 的 AUROC 最高，为 0.769。
- Early Fusion 的 Macro-F1 最高，为 0.666。
- train 指标明显高于 dev/test，说明模型存在过拟合风险。
- 这一版适合展示官方划分下的初步结果，但单个 test split 的不确定性较大。

## 5. result_2：五折固定参数基线

### 方法

- 将 275 人合并后进行分层五折参与者级交叉验证
- 训练每个外层折时固定 Logistic Regression 的 C=1
- 计算每位参与者的折外预测
- 比较 Text、Audio、Video、Early Fusion、Late Fusion

### 结果

| 模型 | Macro-F1 | AUROC |
|---|---:|---:|
| Text | 0.630 | 0.706 |
| Audio | 0.512 | 0.573 |
| Video | 0.540 | 0.558 |
| Early Fusion | 0.556 | 0.568 |
| Late Fusion | **0.588** | **0.605** |

### 结论

- 文本是最强单模态。
- Late Fusion 比 Early Fusion 稳定一些，但整体仍低于 result_1 的官方 test AUROC。
- 五折结果比单次 test 更适合衡量整体稳定性。

## 6. result_3：外层训练折内部选择正则化参数

### 方法

- 每个外层训练折内部再做 3 折交叉验证
- 用内部验证结果选择 Logistic Regression 的正则化参数 C
- 外层验证折始终只用于最终评估

### 结果

| 模型 | result_2 F1 | result_3 F1 | result_2 AUROC | result_3 AUROC |
|---|---:|---:|---:|---:|
| Text | 0.630 | 0.616 | 0.706 | 0.631 |
| Audio | 0.512 | 0.498 | 0.573 | 0.554 |
| Video | 0.540 | 0.498 | 0.558 | 0.529 |
| Early Fusion | 0.556 | 0.532 | 0.568 | 0.539 |
| Late Fusion | 0.588 | 0.536 | 0.605 | 0.560 |

### 结论

- 内层选择 C 没有改善结果，反而下降。
- 小样本下，3 折选择的 C 方差较大。
- 内层优化 AUROC 不保证固定 0.5 阈值下的 Macro-F1 提升。
- result_2 的固定 C=1 仍是较稳的传统特征基线。

## 7. result_4：Linear SVM、随机森林与 XGBoost

### 方法

所有模型使用相同五折划分和相同特征：

- Linear SVM：适合高维稀疏文本
- Random Forest：适合非线性特征关系
- XGBoost：梯度提升树，尝试学习更复杂的非线性关系

### 结果

| 模型 | Text F1/AUROC | Audio F1/AUROC | Video F1/AUROC | Early Fusion F1/AUROC |
|---|---|---|---|---|
| Linear SVM | **0.668 / 0.714** | 0.512 / 0.570 | 0.537 / 0.543 | 0.514 / 0.562 |
| Random Forest | 0.544 / 0.635 | 0.534 / 0.550 | **0.571 / 0.498** | 0.514 / 0.533 |
| XGBoost | 0.483 / 0.632 | 0.473 / 0.555 | 0.488 / 0.482 | 0.496 / 0.574 |

### 结论

- Text + Linear SVM 是传统特征中最好的组合。
- Random Forest 的 Video Macro-F1 较高，但 AUROC 接近随机，说明固定阈值下看起来还可以，概率排序并不可靠。
- XGBoost 在默认 0.5 阈值下偏保守，正类召回率较低。
- 在这批小样本统计特征上，复杂树模型没有超过线性 SVM。

## 8. result_5：外层训练折内部选择分类阈值

### 方法

- 每个外层训练折内部做 3 折预测
- 根据内部预测选择分类阈值
- 将阈值应用到该外层验证折
- 保持 AUROC 的概率计算不变

### 结果

| 模型 | result_4 F1/AUROC | result_5 F1/AUROC |
|---|---|---|
| Text + Linear SVM | 0.668 / 0.714 | 0.582 / 0.714 |
| Video + Random Forest | 0.571 / 0.498 | 0.549 / 0.516 |
| Early Fusion + XGBoost | 0.496 / 0.574 | **0.548 / 0.575** |

### 结论

- 阈值只改变类别预测，不改变 AUROC。
- 阈值选择提升了 XGBoost 的 Macro-F1，但提升很小。
- SVM 的 AUROC 稳定，但内部最佳阈值在外层泛化不稳定。
- 当前传统特征的最佳单项仍是 Text + Linear SVM，Macro-F1 0.668、AUROC 0.714。

## 9. result_6：校准、随机森林和晚期融合权重

### 方法

- 文本：TF-IDF/SVD + Linear SVM，再用 3 折概率校准
- 音频：StandardScaler + Logistic Regression
- 视频：Random Forest，并过滤 OpenFace 检测失败帧
- Late Equal：三个模态概率等权平均
- Late Weighted：在外层训练折内部选择 21 组离散融合权重

### 结果

| 模型 | Macro-F1 | AUROC | Balanced Accuracy |
|---|---:|---:|---:|
| 文本校准 SVM | 0.432 | 0.710 | 0.500 |
| 音频 Logistic Regression | 0.512 | 0.573 | 0.531 |
| 视频 Random Forest | 0.561 | 0.506 | 0.559 |
| Late Equal | 0.534 | 0.609 | 0.544 |
| Late Weighted | **0.571** | 0.534 | **0.568** |

### 结论

- 权重学习提高了 Macro-F1，但降低了 AUROC。
- 文本校准后的概率全部低于 0.5，导致固定阈值下全部预测为负类；AUROC 仍为 0.710，说明排序能力和固定阈值分类能力是两件事。
- Late Weighted 的权重在不同折之间变化很大，部分折完全依赖视频。
- 这是探索性实验，不能证明学习权重稳定优于等权融合。

## 10. result_repo_style：预训练 embedding 五折实验

### 方法

- 文本：RoBERTa-base
- 音频：Wav2Vec2-base
- 视频：OpenFace 统计特征
- 模型：Logistic Regression 和 XGBoost
- 评估：与 result_2 至 result_6 相同的五折参与者级框架

### 结果

| 模型 | 特征 | Macro-F1 | AUROC |
|---|---|---:|---:|
| Logistic Regression | RoBERTa 文本 | 0.655 | 0.755 |
| Logistic Regression | Wav2Vec2 音频 | 0.566 | 0.613 |
| Logistic Regression | OpenFace 视频 | 0.533 | 0.562 |
| Logistic Regression | 三模态 Early Fusion | **0.647** | **0.759** |
| XGBoost | RoBERTa 文本 | 0.573 | 0.717 |
| XGBoost | Wav2Vec2 音频 | 0.513 | 0.633 |
| XGBoost | OpenFace 视频 | 0.541 | 0.581 |
| XGBoost | 三模态 Early Fusion | 0.545 | 0.721 |

### 结论

- RoBERTa 文本明显优于 TF-IDF/SVD 文本基线。
- Wav2Vec2 音频比旧音频统计特征有一定提升。
- OpenFace 视频单独效果有限。
- Early Fusion + Logistic Regression 达到当前最高 AUROC 0.759。
- XGBoost 没有超过 Logistic Regression，说明预训练 embedding 在当前样本量下仍更适合线性分类器。

## 12. 最终研究结论

当前最可靠的结论是：

> 在本项目的 E-DAIC 五折参与者级实验中，预训练文本表示是最有区分能力的特征。RoBERTa 文本单模态 Logistic Regression 达到 AUROC 0.755；将 RoBERTa、Wav2Vec2 和 OpenFace 特征进行 Early Fusion 后，Logistic Regression 达到最高 AUROC 0.759。传统特征中，Text + Linear SVM 是最稳定的基线，Macro-F1 为 0.668、AUROC 为 0.714。

这说明预训练语言表示带来了主要收益，但当前结果不能证明视频一定有效，也不能证明复杂的 XGBoost 或学习融合权重一定优于线性模型。

## 13. 补充分析结果

为完成最后的可靠性检查，又在同一套预训练 embedding 上进行了七种模态组合消融。每种组合都使用 Logistic Regression 和 XGBoost，并使用相同的五折参与者级划分。

### 13.1 Logistic Regression 的七种组合

| 组合 | Macro-F1 均值±标准差 | AUROC 均值±标准差 |
|---|---:|---:|
| Audio | 0.554±0.068 | 0.623±0.094 |
| Video | 0.530±0.051 | 0.572±0.103 |
| Text | 0.649±0.138 | 0.755±0.103 |
| Text + Audio | **0.649±0.100** | **0.757±0.072** |
| Text + Video | 0.616±0.093 | 0.753±0.106 |
| Audio + Video | 0.585±0.065 | 0.612±0.121 |
| Text + Audio + Video | 0.639±0.116 | 0.757±0.102 |

折外整体 AUROC 的 bootstrap 95% 置信区间为：

- Text：0.755，95% CI [0.686, 0.820]
- Text + Audio：0.759，95% CI [0.691, 0.821]
- Text + Video：0.753，95% CI [0.687, 0.815]
- Text + Audio + Video：0.759，95% CI [0.690, 0.824]

Text + Audio 的五折均值略高于三模态，说明当前数据中视频没有带来稳定的额外收益。不同组合的置信区间高度重叠，不能据此宣称某个组合显著优于其他组合。

### 13.2 XGBoost 的消融结果

XGBoost 的最好组合是 Text + Audio，AUROC 均值为 0.726±0.064；三模态组合为 0.720±0.067。它仍然低于 Logistic Regression 的 Text + Audio 和三模态组合。

### 13.3 模型差异检验

- Logistic Regression 三模态与 Logistic Regression 文本：McNemar exact p=0.856；Macro-F1 和 AUROC 的 bootstrap 差异区间都包含 0。
- Logistic Regression 三模态与 XGBoost 三模态：McNemar exact p<0.001；Macro-F1 差异的 95% CI 为 [0.026, 0.178]，AUROC 差异区间为 [-0.018, 0.093]。这支持 Logistic Regression 在固定阈值分类上更好，但 AUROC 优势仍不确定。

### 13.4 官方 test split 的一次性评估

以训练集训练、在 dev/test 上一次性评估 Text、Text + Audio 和三模态 Early Fusion：

| 模型与组合 | Dev Macro-F1 | Dev AUROC | Test Macro-F1 | Test AUROC |
|---|---:|---:|---:|---:|
| Logistic Regression + Text | 0.614 | 0.733 | **0.666** | 0.719 |
| Logistic Regression + Text + Audio | 0.599 | 0.686 | 0.619 | 0.722 |
| Logistic Regression + Text + Audio + Video | 0.614 | 0.691 | 0.641 | **0.768** |
| XGBoost + Text + Audio + Video | 0.525 | 0.636 | 0.535 | 0.712 |

这个官方 split 结果只能作为一次性补充检查，不能与五折折外结果当成同一种评估。

### 13.5 最终模型建议

如果需要固定一个后续使用的研究模型，建议选择 **RoBERTa + Wav2Vec2 的 Early Fusion Logistic Regression**：

- 五折 AUROC 均值最高：0.757
- 特征组合比三模态更简单
- 视频没有显示出稳定增益
- 线性模型在小样本 embedding 上比 XGBoost 更稳定

官方 test split 中三模态的 AUROC 较高，但五折结果没有显示视频带来稳定增益。因此，Text + Audio 是更适合预先固定的研究候选，三模态结果应作为一次性官方 split 检查报告。

这个选择仍属于当前数据集上的研究模型选择，不能视为外部验证后的最终临床模型。
